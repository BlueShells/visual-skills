# TinyCharts

**28 种手绘 2.5D 风格，适合流程、教学、结构演示。**

- 来源/官网：https://april-zhu.com/tinycharts
- 作者：April Zhu（@Aprilzz423）
- 许可/价格：免费版含前 9 种图表；Pro 解锁全部 28 种，并支持根据描述自动选择最合适的图表类型。未找到公开 GitHub 仓库。

## 它做什么

把流程、规则、升级路径、时间线、分支等描述变成可点击、可回放的等距手绘风图表。每个按钮背后是真实的状态图（statechart），点击/分支遵循流程的实际逻辑，而不是一段静态动画。

## 安装

以官网为准。官网提供两种方式：

1. **终端一行命令**：在 https://april-zhu.com/tinycharts 复制安装命令（首次复制需要通过页面的 email gate）。
2. **Claude.ai 上传**：下载 `.skill` 文件后直接在 Claude.ai 中上传。

官网同时提供 `tinycharts.tar.gz` 资源；不要从非官方镜像安装。

## 用法

用自然语言描述你要展示的过程，例如：

> 画一个用户注册与邮箱验证的流程，包含失败重试和人工审核分支。

> 用一个可交互的时间线展示数据库迁移的五个阶段，每个阶段可以点开看细节。

Pro 版还可以让它根据描述自动选图表类型并说明选择理由。

## 产出与限制

- 产出是可交互、可回放的网页/图表，适合教学、方案讲解和流程演示。
- 免费版只有 9 种图表；28 种全量需要 Pro。
- 具体运行要求（浏览器、Claude Code 版本）以官网为准。
